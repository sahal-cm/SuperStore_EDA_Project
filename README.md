## SuperStore_EDA_Project
The Superstore Sales dataset is a widely used retail dataset from Kaggle that contains detailed information about customer orders, products, shipping details, and financial metrics such as sales, discounts, and profit. Each record represents a single transaction and includes important features like order date, ship date, customer segment, region, and product category.
This project explores the Superstore dataset using Python to analyze sales trends, profitability, and business performance. It includes data preprocessing, visualizations, and insights to support better decision-making.
It performs Exploratory Data Analysis (EDA) on the Superstore dataset using Python libraries such as Pandas, Matplotlib, and Seaborn. It includes data cleaning, preprocessing, and detailed analysis of sales, profit, discounts, regions, and product categories. Various visualizations like bar charts, line plots, scatter plots, and heatmaps are used to identify trends, relationships, and patterns. The project highlights key business insights such as the impact of discounts on profitability, top-performing regions and cities, and inefficient sub-categories, helping in better data-driven decision-making.
